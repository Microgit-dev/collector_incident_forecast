# Памятка аналитика

## Метки обучения

«Обучение и обратная связь» → очередь меток. Каждое решение диспетчера с «что произошло»
превращается в метку по правилам «причина → эффект». Проверьте её:

- **принять** — решение подтверждает событие (например, отказ канала);
- **отклонить** — метка ошибочна; её можно отменить и позже.

Влияние меток видно в каждой версии модели: сравнение с контрольной моделью без разметки.

## Данные

- **Здоровье каналов** — Data Health, молчащие каналы, давние обрывы.
- **Качество данных** — отчёты загрузки: корректные измерения, служебные коды, артефакты времени.
- **История** — матрица «каналы × сутки» объекта и ряд канала за любой период.

## Модели

Раздел «Модели»: версии, метрики на валидации, чемпион и претендент. Плановое переобучение — раз в
неделю; при деградации журнала — уведомление. Откат версии — там же.

## Пожар и НСД: вероятность по истории

«Модели» → внизу — калибровка индикаторов: для каждого интервала индекса указано, сколько было
случаев в архиве и в какой доле угроза проявилась. Там же — проверка на отложенном годе.
Пересчёт выполняется раз в неделю автоматически или по кнопке «Пересчитать по архиву».

## Панели Grafana

«Панели Grafana» в меню — бизнес-показатели, только просмотр, вход без пароля (статья
«Интеграции и мониторинг системы»).

## Качество прогнозов

«Аналитика → Качество прогнозов»: точность и доля ложных по журналу, полнота по фактическим
событиям, упреждение, «помог ли прогноз».
