# Поддержка и контакты

> Эту статью заполняет администратор: «Администрирование → Вики → Статьи вики».

| Вопрос | Куда обращаться |
|---|---|
| Не могу войти, забыл пароль | администратор системы |
| Не вижу объект, неверная зона | администратор системы |
| Ошибка в данных датчика | аналитик |
| Система недоступна или работает медленно | дежурный администратор |
| Предложение по улучшению | руководитель подразделения |

## При сбое системы

1. Работайте по резервному регламенту смены.
2. Сообщите дежурному администратору: время, что делали, текст ошибки.
3. После восстановления внесите решения по карточкам, принятые в период сбоя.
