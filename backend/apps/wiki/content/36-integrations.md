# Интеграции и мониторинг системы

## Интеграции (администратор)

Раздел **«Интеграции»** — карточка на каждую внешнюю систему:

| Система | Зачем | Обмен |
|---|---|---|
| СМВУ | поток событий датчиков | чтение из очереди Kafka |
| LDAP / AD | вход и роли | чтение каталога |
| Система учёта заявок | передача утверждённых заявок, статусы, отчёты бригад | передача заявки, остальное — чтение |
| Реестр оборудования | регламент ТО, наработка, ввод в эксплуатацию | чтение (API раз в сутки или файл) |
| Видеонаблюдение | кадры камер у места тревоги | чтение |
| Метеоданные | осадки и оттепель для прогноза подтоплений | чтение открытого API |
| Prometheus и Grafana | метрики и панели | в составе поставки |

У карточки: **режим** («эмуляция» — стенд, «боевой режим» — система заказчика), адрес, последний
успешный обмен и последняя ошибка. **«Проверить связь»** выполняет запрос только на чтение.
**«Синхронизировать»** запускает обмен сейчас, не дожидаясь расписания.

Подключение к системам заказчика настраивается в `.env` без правки кода. Как это сделать, описано
в инструкции по развёртыванию, раздел «Интеграции».

## Grafana и Prometheus

Открываются из меню слева, вход — вашей учётной записью системы, отдельных паролей нет.

| Роль | Что доступно |
|---|---|
| Аналитик | **Панели Grafana** — бизнес-показатели (папка «Аналитика»), только просмотр |
| Администратор | всё выше, **Мониторинг системы** (сервисы, очереди, база) и **Prometheus** |

Если панель открывается со страницей «Нет доступа», откройте её заново из меню: сеанс панелей живёт
8 часов и закрывается при выходе из системы.
