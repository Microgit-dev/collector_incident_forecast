# Учебные задания

Раздел **«Учебные задания»**. Экскурсия по интерфейсу доступна везде, задания со сценариями —
в **учебном контуре** (https://localhost:8443): полигон и симулятор датчиков, на работу района не влияет.

## Как проходит задание

1. Нажмите «Начать» — симулятор разыграет сценарий на объекте полигона вашей зоны.
2. Поверх экрана — **панель задания**: текущий шаг и подсказка.
3. **«Показать где»** подсвечивает нужную кнопку.
4. Шаг засчитывается **по вашему действию в системе** (принята карточка, выбрана причина,
   утверждена заявка), а не по кнопке «далее».
5. Неверное решение — объяснение, почему правильно другое; ошибка учитывается в результате.

## Задания

| Задание | Для кого |
|---|---|
| Знакомство с интерфейсом | все роли |
| Пожар: от сигнала до решения | диспетчеры |
| Неисправный датчик — не событие | диспетчеры |
| Проникновение на объект под охраной | диспетчеры |
| Заявка по карточке: утвердить и передать | руководитель |
| Метка из решения диспетчера | аналитик |
| Исполнение заявки | бригада |

Лучший результат (время, ошибки) сохраняется; руководитель видит результаты сотрудников зоны.
