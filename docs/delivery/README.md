## Пересборка

Документация собирается из `documentation.md`, инструкция по развёртыванию — из `docs/deployment.md`,
руководства по ролям — из `docs/guides/` (все документы — одной командой ниже). Главы-методики подключаются из `docs/*.md` директивой
`<!-- include: … -->`, поэтому текст методик существует в одном экземпляре.

```bash
cd backend && uv run python ../docs/delivery/gen_libraries.py        # перечень библиотек → libraries.md
cd .. && uv run --no-project --with python-docx --with pywin32 python docs/delivery/build.py
```

PDF документации и презентации делают Microsoft Word и PowerPoint (COM). Без Office собирается
только DOCX.

Презентация собирается на шаблоне конкурса (`data/ЛЦТ2026 Шаблон презентации.pptx`): обязательные
слайды 7–11 заполняются в исходных фигурах, остальные слайды шаблона удаляются, описательная часть
(BPMN-схемы и ML-конвейер — нативными фигурами PowerPoint) добавляется на его макетах. Данные команды
для слайдов 8–10 — словарь `TEAM` в начале скрипта.

```bash
uv run --no-project --with python-pptx --with pywin32 python docs/delivery/presentation.py
```
