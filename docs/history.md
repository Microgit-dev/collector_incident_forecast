# Режим просмотра истории

Раздел «История» в меню. Он доступен ролям, которым видна телеметрия: диспетчерам, руководителю,
аналитику, наблюдателю и администратору. Выборка ограничена зоной ответственности. Каждый просмотр
канала попадает в журнал действий (`history.channel`).

## Что показывается

**Объект целиком** — матрица «каналы × сутки»:
- клетка окрашена по худшему состоянию канала за сутки: тревога → неисправность → нет питания →
  не определено → норма;
- первыми идут каналы с наибольшим числом нештатных суток, на странице до 60 каналов;
- «без данных» — каналы без единого сообщения за период: канал молчал или его ещё не было, потому что
  справочник отражает текущий состав оборудования;
- ниже — сколько каналов объекта было не в норме по дням и карточки объекта за период.

Щелчок по строке открывает историю канала.

**Канал** — все дорожки на одной оси времени:
- **Показания.** До месяца — сырые показания. Если точек больше 600, ряд сжимается в интервалы от
  1 минуты до суток: линия — среднее, полоса — от минимума до максимума. Поверх — пороги
  предупреждения и тревоги из профиля датчика. Служебные коды и артефакты даты показаны красными
  штрихами, а не значениями.
- **Состояния по аспектам.** Основное, питание, работа насоса или вентилятора, охрана — интервалы с
  исходной строкой СМВУ во всплывающей подсказке. Состояние на начало периода берётся из последнего
  сообщения до него.
- **Карточки** по каналу — ромб в момент открытия, полоса — пока карточка открыта. **Прогнозы** по
  каналу — размер точки соответствует вероятности.
- **По суткам.** Нештатные и невалидные сообщения, минимум, среднее и максимум показаний.
- **Решения того времени.** Таблица карточек по каналу с решением диспетчера («что произошло», кто,
  когда). Отдельно — карточки на том же объекте в то же время.

Длиннее месяца (до трёх лет) канал показывается по суточной витрине.

## Откуда берутся данные

| Период | Источник |
|---|---|
| До начала оперативного контура | Parquet-архив журналов по годам (`artifacts/archive/journal_<год>.parquet`) |
| С начала оперативного контура | hypertable `telemetry_reading` |
| Любой период по суткам | суточная витрина `telemetry_channeldaily` |

Если период захватывает оба источника, показания склеиваются на границе. Какие источники
использованы, видно в заголовке канала. Архив разбит на группы строк по времени, поэтому неделя
одного канала читается за ~0,2 с, квартал — за ~0,5 с.

Перейти в историю можно из карточки инцидента (ссылка «история» у сигнала) и из карточки прогноза
(«история канала»). В адресе хранятся объект, канал и период, поэтому ссылку можно переслать.

## API

| Запрос | Ответ |
|---|---|
| `GET /api/v1/history/channel/?channel=&from=YYYY-MM-DD&to=YYYY-MM-DD` | Канал за период: показания или интервалы, состояния, невалидные значения, сутки, карточки, прогнозы |
| `GET /api/v1/history/node/?node=&from=&to=` | Объект: сутки, матрица каналов, итоги по дням, карточки (период до года) |
| `GET /api/v1/history/coverage/` | Годы архива, границы суточной витрины и оперативного контура |
| `GET /api/v1/assets/channels/?within=<узел>` | Каналы поддерева (для выбора канала) |
