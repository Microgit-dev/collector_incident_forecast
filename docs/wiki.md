# Вики для сотрудников

Раздел «Вики» — справка внутри системы: регламенты смены, памятки по ролям, описание рисков,
обучение и учения, глоссарий, частые вопросы, контакты поддержки.

- **Правка — из админки, без второго входа.** Кнопка «Редактировать» у статьи и «Мои задачи» в
  разделе «Администрирование» открывают админку текущим входом, раздел «Информационная база».
  Статьи добавляют руководитель и аналитик, разделы и публикацию ведёт руководитель
  (матрица в [platform.md](platform.md)). Вики одна на платформу: в учебном контуре показывается
  она же. Текст пишется в
  Markdown: заголовки, списки, таблицы, ссылки на страницы системы, примечания. У статьи задаются
  раздел, порядок и роли; пустой список ролей — статья видна всем. Снятый флаг «опубликована»
  превращает статью в черновик, который видят только редакторы. Кто и что изменил, хранит
  django-auditlog.
- **Чтение.** Слева оглавление и поиск по тексту, справа статья. Внутренние ссылки открываются без
  перезагрузки, HTML из текста не исполняется. Редактору у статьи видна кнопка «Редактировать».
  На телефоне страница работает в два шага: оглавление → статья.
- **Начальное наполнение** — 22 статьи из `backend/apps/wiki/content/*.md`. Их загружает `bootstrap`
  при развёртывании. Существующие статьи не перезаписываются, поэтому правки из админки сохраняются;
  `manage.py seed_wiki --force` вернёт исходный текст.

API: `GET /api/v1/wiki/[?q=]` — оглавление по ролям пользователя; `GET /api/v1/wiki/{slug}/` — статья.
