# Памятка для проверяющего

Короткий путь по системе: где что открыть, под какой учётной записью войти и что проверить за
20–30 минут. Подробно — «Общее руководство пользователя» и руководства по ролям.

## 1. Адреса

Адрес стенда: **https://collector-forecast.duckdns.org**. Все разделы — на одном адресе.

| Что | Адрес |
|---|---|
| Система (рабочий контур) | https://collector-forecast.duckdns.org/ |
| Учебный контур (полигон Мю, Кси, Тау) | https://collector-forecast.duckdns.org/training/ |
| Симулятор датчиков | https://collector-forecast.duckdns.org/simulator/ — открывать из меню учебного контура «Симулятор датчиков» |
| Эмулятор системы заявок заказчика | https://collector-forecast.duckdns.org/helpdesk/ (учебного контура — https://collector-forecast.duckdns.org/training/helpdesk/) |
| Документация API (OpenAPI) | https://collector-forecast.duckdns.org/api/docs/ |
| Админка | https://collector-forecast.duckdns.org/admin/ — тем же входом, второй пароль не нужен |
| Панели Grafana | меню «Панели Grafana» / «Мониторинг системы» (аналитик, администратор) |
| Prometheus | меню «Prometheus» (администратор) |

Браузер — Chrome или Яндекс Браузер. На телефоне — тот же адрес, «Добавить на главный экран».

## 2. Учётные записи

Пароль всех тестовых сотрудников: **`Passw0rd!`**. Учётная запись администратора стенда — `admin` /
`admin12345`. Если пароль не подходит, его сменили на стенде — уточните у команды.

| Роль | Логин | Зона |
|---|---|---|
| Руководитель подразделения | `head.sidorova` | весь район |
| Диспетчер ОДС | `ods.ivanov`, `ods.kozlova` | весь район |
| Диспетчер подразделения | `disp.petrov` (Мю), `disp.nikolaev` (Кси), `disp.fedorova` (Тау) | объект |
| Ремонтная бригада | `brigade.smirnov` (Мю), `brigade.popov` (Кси), `brigade.egorov` (Тау) | объект |
| Аналитик | `analyst.kuznetsov` | весь район |
| Администратор | `admin.volkov` | весь район |
| Наблюдатель | `observer.orlova` | весь район |

Удобно открыть две роли сразу: вторую — в окне инкогнито.

## 3. Маршрут проверки

### 3.1 Авария от сигнала до решения (10 минут, учебный контур)

1. Войдите `head.sidorova`, переключатель в шапке → **«Учебный контур»**, меню → **«Симулятор
   датчиков»**.
2. В панели **«Готовые сценарии»** выберите «Ночь: проникновение и возгорание», ускорение ×30,
   **«Запустить»**. Под описанием — что должен сделать диспетчер.
3. Во втором окне войдите `disp.nikolaev` (диспетчер объекта Кси), учебный контур, **«Рабочее место»**:
   через несколько секунд появится карточка «Несанкционированный доступ», затем «Пожар».
4. Откройте карточку НСД: эпизод, гипотезы, **маршрут нарушителя** по пикетам, чек-лист, проверка по
   камерам. **«Принять»** → **«Решение»** («Направлена проверка», что произошло — «Реальное событие»).
5. Откройте карточку пожара → **«Решение»** («Выезд бригады») → **«Черновик заявки»**.

### 3.2 Заявка до закрытия (5 минут, учебный контур)

1. `head.sidorova`, учебный контур → **«Заявки и ТО»**: черновик → **«Утвердить»** (исполнитель подставился сам) →
   **«Передать в систему заявок»**.
2. https://collector-forecast.duckdns.org/training/helpdesk/ — та же заявка «с их стороны»; её стадии идут сами по времени или по кнопке.
3. `brigade.popov` (телефон или узкое окно), учебный контур → **«Мониторинг»**, режим «Заявки» → **«Взять в работу»**
   → **«Выполнена»**: что сделано, состояние оборудования.
4. `disp.nikolaev` → карточка пожара: в хронологии — отчёт бригады; **«Решение»** → «Устранено».
   Карточка переходит в «Решён».

### 3.3 Прогнозы и данные (5 минут, рабочий контур)

1. `analyst.kuznetsov` → **«Журнал прогнозов»**: вероятность за 24 часа, уровень, причины.
2. **«Модели»**: три модели LightGBM, метрики на отложенном 2026 годе, калибровка пожара и НСД.
3. **«Конструктор датчиков»**: шаблон из библиотеки, пример сообщения в песочнице → «Проверить».
4. **«Панели Grafana»** — бизнес-показатели.

### 3.4 Карта и объекты (5 минут)

1. **«Мониторинг»**: режимы Обстановка / Прогноз / Датчики / Данные / Заявки, спутниковый снимок.
2. `head.sidorova` → **«Зоны и объекты»**: инструмент **«По снимку (ИИ)»** обводит здание по снимку;
   двойной щелчок по вершине удаляет лишнюю точку. Вкладка **«Этажи»**: загрузить план, привязать по
   контрольным точкам, прозрачность.

### 3.5 Прочее

- **Учения**: `head.sidorova`, учебный контур → «Учения» → сценарий, участники, старт → разбор.
- **Учебные задания**: любой пользователь → «Учебные задания».
- **ТО**: инженер ТО (`admin.volkov` видит все разделы) → «План ТО», «Графики ТО и ППР».
- **Администрирование**: `admin.volkov` → «Мои задачи», «Интеграции», «Команды».
