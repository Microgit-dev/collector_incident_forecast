# Руководства пользователя по ролям

Для каждой роли — своё руководство: что роль делает в системе, какие у неё экраны, как пройти типовые
ситуации по шагам, чего роль не делает. Руководства собираются в DOCX и PDF командой сборки пакета
сдачи (`docs/delivery/build.py`) в `docs/delivery/out/Руководства/`.

| Роль | Руководство | Главное |
|---|---|---|
| Диспетчер ОДС | [dispatcher-ods.md](dispatcher-ods.md) | Карточки всего района: отклик, проверка, решение, черновик заявки |
| Диспетчер подразделения | [dispatcher-unit.md](dispatcher-unit.md) | То же в своей зоне; проверка по камерам; передача смены |
| Руководитель подразделения | [head.md](head.md) | Эскалации, перехват, утверждение заявок и графиков ТО, структура зоны, учения, отчёты |
| Аналитик | [analyst.md](analyst.md) | Метки обучения, модели и калибровка, качество данных, конструктор датчиков, Grafana |
| Инженер ТО | [maintenance-engineer.md](maintenance-engineer.md) | План ТО, реестр и осмотры, графики ТО и ППР в формах заказчика, регламент |
| Ремонтная бригада | [brigade.md](brigade.md) | Свои заявки с телефона: взять в работу, выполнить, указать состояние оборудования |
| Наблюдатель | [observer.md](observer.md) | Только просмотр обстановки своей зоны |
| Администратор | [admin.md](admin.md) | Пользователи и роли, интеграции, справочники, мониторинг системы |

Общее для всех ролей — вход, зона ответственности, сообщения, вики, работа с телефона — повторено
в начале каждого руководства: его можно читать и печатать отдельно.
