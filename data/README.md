# data/

Сырые данные заказчика. В git не попадают (см. `.gitignore`), в контейнеры монтируются read-only в `/data`.

Ожидаемая структура:

```
data/
  8. ДЖКХ.pdf                         # техническое задание
  Город 8. ДЖКХ.xlsx                  # вопросы и ответы заказчика
  dataset/
    справочник_каналов_датчиков.csv   # 11 485 каналов, связь с объектом через ид_объект
    справочник_объектов_диспетчер.csv # дерево объектов: район → объект → ДП/охраняемый объект
    справочник_состояний.csv          # возможные текстовые состояния по типам датчиков
    журнал_событий_пример.csv         # один день журнала (true/false)
    journals/ext-journal-YYYY.csv     # журналы 2019–2026 (t/f), ~14 ГБ
```

Формат журнала: `ид_события,ид_канала_данных,дата,время,тревожное,значение_датчика`.
Правила интерпретации значений — см. [docs/data-methodology.md](../docs/data-methodology.md).
